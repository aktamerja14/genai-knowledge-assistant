
# GenAI Knowledge Assistant

A practice project for learning Generative AI application development.

## Planned Features

- LLM integration and reusable prompt templates
- Sequential, parallel and conditional chains
- Output parsing and structured responses
- PDF and text document loading
- Text splitting and embeddings
- Vector storage and semantic search
- Retrieval-Augmented Generation (RAG)
- Conversational history and memory
- Tool calling
- Testing and Git/GitHub workflows

## Technology

- Python
- LangChain
- Configurable LLM and embedding providers
- Chroma vector database
